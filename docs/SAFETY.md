# 安全注意事项与禁止事项

## 一、安全注意事项（必看）

1. **删除不可恢复**。视频号列表页删除后无独立回收站可回退，因此：
   - 必须先 `dry-run` 出清单；
   - 必须人工核对；
   - 必须明确回复「确认删除」才执行。

2. **后台运行不等于无人值守**。第一次运行请务必小样本（`--limit 3`）观察，确认日志里的 `how=dom-action confirm=dom`（最可靠路径），再放量。

3. **别动那个 Edge 窗口**。程序的点击按页面坐标派发，你同时去点它会让程序点歪。可以最小化、可以被其他窗口盖住，但不能关闭、不能退出登录。

4. **本工具的边界**：
   - 只处理本机 Edge 已登录的**本人账号**；
   - 只删除**指定时间范围内**的视频；
   - 不读、不传、不改任何 Cookie / 密码 / 个人信息；
   - 不访问任何第三方服务器。

5. **登录态保护**：`.edge-profile/` 目录里存着你的登录凭据，**不要把这个目录分享或上传**。

6. **限流是正常现象**。出现「操作过于频繁」时程序会自己等 1 小时再试，不要手动干预页面。连续 5 次仍失败会自动停手，这时隔几小时再跑。

---

## 二、禁止事项（硬性）

1. 禁止在用户未明确回复「确认删除」前执行任何删除。
2. 禁止把时间范围推断、四舍五入、扩大或默认成"全部视频"。
3. 禁止删除日期无法解析的条目（只能列出并跳过）。
4. 禁止用固定屏幕坐标代替元素定位；禁止在没有成功判定时盲点。
5. 禁止连续快速点击「下一页」遍历列表（会触发限流）。
6. 禁止把「列表 0 条」「页数变少」当成"已删完"或"本来就没视频"。
7. 禁止点「发表视频」「置顶」「分享」「修改描述和封面」「可见权限」「退出登录」等无关按钮。
8. 禁止自动滑验证码、自动识别验证码、自动处理手机二次确认。
9. 禁止为了提速把删除间隔设为 0，或关闭限流等待与重试上限。
10. 禁止同时运行多个实例操作同一账号、同一浏览器。
11. 禁止在未复核「范围内条目数 == 0」前输出"已全部删除完成"。
12. 禁止省略三态记录（已收集 / 已删除 / 剩余）与每步日志。
13. 禁止把 `.edge-profile/`、`state.json`、`logs/` 上传到任何地方。

---

## 三、数据与隐私

| 文件 | 包含什么 | 处理建议 |
|---|---|---|
| `.edge-profile/` | 浏览器登录态（Cookie 等） | 不要分享、不要上传、用完可整体删除 |
| `state.json` | 视频标题、日期、处理状态 | 本地保存，不要外传 |
| `logs/` | 操作日志、可能含标题 | 本地保存 |
| `shots/` | 失败截图 | 默认运行结束自动清空 |

---

## 四、异常情况下的数据安全

程序所有写入都是**原子写**（临时文件 + 重命名），断电、崩溃、强杀都不会损坏 `state.json`。

若担心误删，删除前自行导出清单 CSV 留档即可；视频本身一旦删除无法找回。
