# 使用示例

## 示例 1：删除某段完整年份范围

```
我：删除 2022-01-01 到 2025-12-31 发布的全部视频。

Agent（或程序）：
  1. 打开列表，读到「视频 (2760)」
  2. 逐页收集，输出 dryrun-20261027-143720.csv
  3. 打印清单：范围内 2685 条，范围外 75 条（2026 年）
  4. 等待你回复「确认删除」
你：确认删除
Agent（或程序）：
  5. 分批删除，每批 20 条，实时更新三态
  6. 跑完复核：范围内条目数 == 0
  7. 输出完成报告
```

## 示例 2：只删某一个月

```
我：删除 2024-03 的视频。
→ 解析为 2024-03-01 到 2024-03-31（含首尾两天）
→ 清单 → 确认删除 → 执行 → 复核
```

## 示例 3：最近 30 天

```
我：删除最近30天的视频。
→ 若今天是 2026-10-27，则范围是 2026-09-28 到 2026-10-27（含今天）
```

## 示例 4：非法输入

```
我：删掉去年的。
→ 程序输出：
   无法识别你输入的时间范围：去年的
   请按以下任一格式重新提供：
     1) 2022-01-01 到 2025-12-31
     2) 2024-03
     3) 最近30天
（不会继续执行任何删除）
```

## 示例 5：命中限流的完整恢复

```
14:48:41 检测到「操作过于频繁」
14:48:41 记录现场：第 12 页、正在删《#创业 ...》、页面视频 2732、规则 selectors.risk_signals
14:48:41 进入冷却，预计 15:48:41 恢复
15:48:41 探测：页面无提示、列表 20 条、总页数 137（≥ 138×0.9 的边缘，满足）
15:48:42 恢复，继续删除第 13 页
```

## 示例 6：中断与续跑

```
:: 中途想停
echo stop > .stop            :: 优雅停止
:: 过几小时继续（断点全在）
run.bat run --yes --skip-collect
```

## 示例 7：用 Agent 加载

```
我：@channels-video-batch-delete 删除 2022-01-01 到 2025-12-31 的视频。
（Agent 加载 SKILL.md，按流程执行，列出清单等你确认）
```
