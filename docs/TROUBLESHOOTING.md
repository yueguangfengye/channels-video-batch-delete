# 异常处理

## 一、速查表

| 现象 | 判定 | 必须执行的动作 |
|---|---|---|
| 地址含 `login.html` 或出现「扫码登录」 | 未登录 | 停止，请用户扫码；不自动尝试登录 |
| 顶部出现「操作过于频繁」 | 内容管理限流 | 记录现场 → 立即探测恢复 → 继续，最多 5 次 |
| 列表 0 条，显示「你还没有发表过视频」 | 接口未返回数据 | 按限流处理；**禁止**据此宣布删完 |
| 总页数从 138 变成 10，数据只剩百余条 | 数据被截断（隐性限流） | 同上限流处理，不得把残量当全量 |
| 点删除后无弹窗 | 可能点到纯文字标签 | 改点 `div.opr-item-wrap` 容器；仍无效则报「页面不匹配」 |
| 弹窗只有标题栏、找不到确定按钮 | 弹层容器取错 | 向上扩展到同时含「取消」「确定」的容器再判定 |
| 点确定后弹窗关闭但列表未变 | 列表不自动刷新（正常） | 以「已删除」toast 为准，继续从下往上删 |
| 出现滑块、安全验证 | 需要人工 | 立即暂停，提示用户，不得自动尝试 |
| 页面跳到草稿箱等无关页 | 误点导航 | 停止，报告 `页面不匹配：进入了<页面名>` |
| 连续 3 轮零删除 | 被限制或结构变化 | 停止并输出诊断，不空转 |
| 连点「下一页」十几次后页数骤减 | 翻页限流 | 改用页码输入框跳页，不再连点 |
| 连续 5 次探测仍被限制 | 限制未自愈 | 停止，生成 `RESTRICTION-REPORT.md`，转人工 |

## 二、限流自愈的判定条件（三条同时满足才继续）

1. 页面不再出现任何限流/验证码文字；
2. 列表能正常扫到条目且条数 > 0；
3. 分页总页数 ≥ 预期的 90%。

任一不满足 → 继续下一次探测（不等待）。

## 三、断点续跑

所有进度都存在 `state.json`，每条视频一个状态：

| 状态 | 含义 |
|---|---|
| `pending` | 待处理 |
| `deleted` | 已删除 |
| `failed` | 多次重试仍失败 |
| `skipped` | 明确跳过（已不存在/范围外） |

中断后重跑会自动跳过 `deleted` / `trashed` / `skipped` 的条目。

```bat
run.bat run --yes --skip-collect    :: 不重扫，直接用断点继续
```

## 四、手动干预接口

| 文件 | 效果 |
|---|---|
| 建 `.pause` | 下一次检查点暂停 |
| 建 `.resume` | 恢复运行 |
| 建 `.stop` | 优雅退出，保存断点 |

都在本包根目录，建一个空文件即可（`type nul > .pause`）。

## 五、常见启动问题

**Q: `start-edge.bat` 跑完端口不通**
说明你已有 Edge 在跑，参数被转交了。把所有 Edge 窗口关掉再跑。

**Q: `run.py probe` 报「连不上 Edge 调试端口」**
同上，或 `config.yaml` 的 `cdp.port` 与 `start-edge.bat` 的 `PORT` 不一致。

**Q: `run.py inspect` 显示 0 条**
1. 确认停在「内容管理 → 视频」页；
2. 手动滚一下让列表加载；
3. 仍是 0 → 把 inspect 输出发给维护者。

**Q: 日志里 `how=coordinate` 很多**
DOM 没命中（按钮要 hover 才显示）。把 `locate.click_verify_wait` 调到 `0.8`，或给 `selectors.more_texts` 补页面实际文案。

**Q: 找不到垃圾桶入口**
本工具已确认：视频号后台无独立回收站，列表页删除即最终删除，`trash.enabled` 默认 `false`。
